# Weekly Growth Review

Copy the template below into a new dated section each week. Keep every past week's entry — this file is a running log, not a doc that gets overwritten.

## Workflow (run through in this order, every week)

1. Review installs (`data/campaign-data.csv`)
2. Review CPI (`data/campaign-data.csv`, `data/creative-data.csv`)
3. Review creative performance (`CAMPAIGN_TRACKER.md` decisions, `data/creative-data.csv`)
4. Review retention (`RETENTION.md`, `data/retention-data.csv`)
5. Review playtime (`data/retention-data.csv`)
6. Review ad revenue (`MONETIZATION.md` real-data log)
7. Identify strongest creative concepts (candidates for `creatives/winners/`)
8. Identify weakest concepts (candidates for `creatives/losers/`)
9. Create next creative batch (new `creatives/concepts/` entries, or ITERATE variants per `CAMPAIGN_TRACKER.md`)
10. Decide: increase, maintain, or reduce paid spend (per `FACEBOOK_ADS.md` phase gating — do not decide on CPI alone)
11. Document conclusions (below)
12. Create next week's experiments (draw from or add to `EXPERIMENTS.md`)
