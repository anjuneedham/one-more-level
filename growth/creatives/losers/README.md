# Losers

Creatives that reached a **PAUSE** decision in `CAMPAIGN_TRACKER.md`. Logged here so the same mistake isn't retested blindly — a PAUSE with a documented reason is worth more than the creative itself.

When a creative earns PAUSE: copy its row from `data/creative-data.csv`, paste it below as a dated entry, and write down the most likely reason it underperformed (weak hook, wrong format, bad timing, unlucky audience) — distinguish "this hook doesn't work" from "this execution of the hook didn't work," since only one of those should retire the underlying concept from `hooks/hook-library.md`.
