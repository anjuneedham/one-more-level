# Platform Captions

Per-platform caption variants for each creative concept. Never copy-paste the identical caption across platforms — it reads as automated and underperforms everywhere (same rule as `CONTENT_ENGINE.md`). Facebook/Instagram ad primary text lives in `CREATIVE_LIBRARY.md`; this file is for organic posts and any paid creative's platform-native caption variant.

## A. CHALLENGE
- **TikTok:** bet you can't clear this in one try 👀 #mobilegame #onemorelevel
- **Instagram Reels:** 25 mini-challenges. This is one of the easy ones.
- **Facebook Reels:** Most people don't make it past level 8. You?
- **YouTube Shorts:** Can you beat One More Level? (25 challenges, 1 shot)

## B. CURIOSITY
- **TikTok:** this looks easy... it's not 🫠
- **Instagram Reels:** watch what happens at 0:07
- **Facebook Reels:** I did not see that coming
- **YouTube Shorts:** This level looks easy. It isn't.

## C. RAGE / FAILURE
- **TikTok:** one jump away. ONE. #rage #mobilegaming
- **Instagram Reels:** send help, I can't stop
- **Facebook Reels:** so close and yet
- **YouTube Shorts:** I was one jump from my best run ever

## D. PROGRESSION
- **TikTok:** level 1 vs level 25 (25 mini-challenges, 1 run)
- **Instagram Reels:** watch the difficulty climb 📈
- **Facebook Reels:** from level 1 to level 25 in one run
- **YouTube Shorts:** One More Level: Level 1 → Level 25

## E. SKILL
- **TikTok:** how many tries would YOU need 😅
- **Instagram Reels:** comment your guess before you watch the end
- **Facebook Reels:** be honest, first try or nah
- **YouTube Shorts:** How Many Attempts Would This Take You?
