# Fonts

Latin subsets downloaded from Google Fonts, used only to render ad captions and end cards (not shipped in the game).

- `archivo-black.woff2`: Archivo Black by Omnibus-Type, SIL Open Font License 1.1
- `inter-600.woff2`: Inter by Rasmus Andersson, SIL Open Font License 1.1

Archivo Black is the display face `src/core/theme.ts` already names as the game's fallback.
