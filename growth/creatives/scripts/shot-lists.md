# Shot Lists

Shot-by-shot breakdowns live inline in each concept's spec in `CREATIVE_LIBRARY.md` (per-second breakdowns for the 15s/20s/30s cuts). This file is the capture checklist to run through in one recording session so a single sitting can produce raw material for all 5 concepts at once — matches the repurposing workflow in the content plan.

## One recording session, all 5 concepts

Record in this order (screen recorder on, portrait, sound on, `npm run dev` or the deployed web build open):

1. **Concept A (Challenge):** One clean full clear, level 12–18 range, timer visible. Re-take until it's smooth (no fumbled taps).
2. **Concept B (Curiosity):** Multiple attempts at a puzzle/memory challenge until a genuine, surprising fail happens. Do not stage it.
3. **Concept C (Rage):** Play until a real last-life death happens on a motion/precision challenge, ideally a close miss. Needs patience — don't force an early take.
4. **Concept D (Progression):** Short clips (1–2s) across the full range: one easy-band level, one normal, one hard, one expert (level 20+). Capture the level counter clearly in each clip.
5. **Concept E (Skill):** Multiple attempts at one precision challenge, 3–4 takes, last one a clean clear.

## Post-capture checklist
- [ ] Trim each clip to just the relevant moment (no dead air at start/end)
- [ ] Confirm level/score/lives counters are legible in every clip that needs them
- [ ] Export at native resolution, no compression artifacts
- [ ] File raw clips under a dated folder outside this repo (raw footage is not committed here — only scripts, decisions, and results are)
- [ ] Cross-check each edited cut against its concept's opening/closing frame spec before publishing
